# 8X8-Sequential-Multiplier-Using-Verilog
RTL-to-GDSII ASIC flow of an 8x8 sequential multiplier in SystemVerilog using Cadence. Tailored for low-power SoCs with an 8-cycle shift-and-add FSM controller and 16-bit joint accumulator. Verified via dynamic testbenches, with full physical design executed from Genus synthesis through Innovus P&amp;R to layout.
